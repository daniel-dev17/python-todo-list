# Python To-Do List

A simple console-based To-Do List application written in Python.

## Description

This program allows you to manage your tasks directly from the terminal.  
You can add new tasks, view the current list, and delete tasks by their number.

## Features

- Show all tasks
- Add a new task
- Delete a task by number
- Simple and clean console interface

## How to run

1. Make sure you have Python installed
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the program:

```
bash
python todo.py
```
